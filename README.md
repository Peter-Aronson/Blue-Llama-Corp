# EntraID Configuration, Identity Access Management, Governance, Provisioning, Hands-On Deployment Project
## Organization: Blue Llama Group (Corp.)
### Project Summary:
This is a Lab centered around Microsoft Entra ID, with a focal point on Identity Access Management. This project, over the course of about a month of daily efforts, seeks to display the provisioning and separation of workspaces, users, permissions. This project will also include a JML (Joiner/Mover/Leaver) framework, with a custom automated user lifecycle management tool created by me. 

### Project Goal:
The overall goal of Project Blue Llama is to show proficiency in EntraID provisioning, understanding of IAM fundamentals, and create baseline experience with managing an EntraID environment. This project may also be used in a later project for attack/defend simulations. The process of Project Blue Llama will be:<br>
-Design a mock organization comprising of 62 total seats across 9 different and unique departments within EntraID.<br>
-Enforce Identity Access Management (IAM) features, Role-Based Access Controls, Principles of Least Privilege and Separation of Duties, Login Safeguards such as Multi-Factor Authentication (MFA) mandating & Password Policies, Joiner/Mover/Leaver feature with an eventual automated tool, and auditing frameworks.<br>
The entirety of this project will be designed, documented, and written by hand, with the only AI influence being to help organization/formatting efforts, creating visual diagrams, and rating accuracy/realism.

### Project Methodology:
This project will follow a custom Waterfall methodology. The idea is to sequentially iterate through tasks, beginning with a Planning phase (which is where I am finishing up now as of 9/27/2026), moving on to a Infrastructure Design phase, where I design the internal architecture, add the users and departments, and ensure everything is set up for policy and group implementation. Next up will be Implementation, where I implement all of the planned features, role based access controls, IAM, MFA, SSO, Password policies, etc. Final stage will be QA/Testing to ensure the project is accurate, realistic, and polished. The project will have a deadline of 10/27/2026, and will have daily work efforts, which will be tracked with a changelog in the corresponding category.
